FAQ

Common questions.

Still have questions? Contact us →

Is this actually using real AI?

Yes — 100%. Every preset is generated in real time by a two-stage AI pipeline running on Claude Opus 4 (Anthropic's most powerful model). Stage 1 (Vocal Intelligence Engine) uses live web search to research the artist's real production history. Stage 2 (Preset Architect) converts that into precise, production-ready plugin values. No pre-stored presets — engineered from scratch every time.

How accurate are the settings?

For well-known artists with documented production styles, the character and direction will be very accurate. The EQ curve shape, compression character, reverb type and size, and saturation level will closely match the artist's sound. Exact numerical values are a strong starting point — vocal processing involves creative intuition that can vary track-to-track, but you'll get 80–90% of the way there instantly. The AI explains its reasoning, so you can refine intelligently.

Does it use Spotify audio?

No. Spotify doesn't permit third-party audio playback or analysis via their API. We use the Spotify link to identify the artist, then our Vocal Intelligence Engine (Opus 4 + Web Search) actively searches for and synthesizes production data — documented techniques, interview quotes, known gear, mix engineers — before the Preset Architect converts that into calibrated plugin settings. More comprehensive than raw audio analysis.

Which plugins and DAWs are supported?

Output covers FabFilter Pro-Q3, Pro-C2, Valhalla Room, iZotope Nectar 3, Waves SSL E-Channel, and common delay/saturation plugins. The settings are parameter-based (not proprietary preset files), so they work in any DAW — Ableton Live, Logic Pro, FL Studio, Pro Tools, Cubase, or Studio One. Just read the values and dial them in.

What if I don't have those exact plugins?

No problem. The AI explains the purpose behind every setting — not just the number. If you see "Bell boost +4dB @ 4.8kHz, Q 0.9" you can dial that in on any EQ. The AI summary tells you the character to aim for, so you can use whatever plugins you have. The guide section also suggests free alternatives for each plugin category.

How long does analysis take?

Typically 30–60 seconds for the full two-stage pipeline. Stage 1 (Vocal Intelligence Engine) runs web searches and builds the production profile; Stage 2 (Preset Architect) engineers the precise parameter values. You can watch the AI processing stream in real time as it works.
